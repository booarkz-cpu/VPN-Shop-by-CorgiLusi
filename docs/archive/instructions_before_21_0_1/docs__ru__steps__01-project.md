# 01. Что лежит в проекте

1. Откройте [README](../../../README.md) для текущего статуса выпуска.
2. Код API, Telegram-бот и фоновый работник находятся в `backend/`; миграции базы — `backend/alembic/versions/`.
3. Интерфейсы лежат отдельно: `admin/` — сотрудники, `cabinet/` — покупатели, `miniapp/` — Telegram.
4. `support-pro/` — отдельная служба заявок; `mobile/` — мобильные клиенты.
5. `docker-compose.yml` связывает сервисы, `deploy/` содержит серверную установку, `scripts/` — проверку и обслуживание, `tests/` — проверки кода.

Для изменений кода начните с соответствующей папки; конфигурацию скопируйте из `.env.example`, но **никогда** не коммитьте `.env` и ключи. Подробная карта функций — [здесь](../FUNCTION_GUIDE.md).
