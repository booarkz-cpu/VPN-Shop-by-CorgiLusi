# Начните здесь: простые инструкции

Читайте только тот файл, который соответствует вашей задаче. Команды выполняйте по порядку; заменяйте адреса `example.com` своими. Если команда завершилась ошибкой, остановитесь и устраните её до следующего шага.

| Задача | Инструкция | Что получится |
| --- | --- | --- |
| Понять состав проекта | [01 — структура](01-project.md) | Найдёте нужную часть кода |
| Проверить магазин без реальных денег | [02 — тестовый стенд](02-local-test.md) | Локальный магазин и тестовая покупка |
| Установить на VDS | [03 — сервер](03-vds.md) | HTTPS, админка, бот и кабинет |
| Настроить и проверить платежи | [04 — платежи](04-payments.md), [все кассы отдельно](../ALL_PAYMENT_PROVIDERS_BEGINNER_CHECKLIST.md) | Понятный порядок staging проверки |
| Обновить и восстановить | [05 — обслуживание](05-operations.md) | План безопасного обновления |

**Статус:** в релизе 20.0.18 полный staging E2E v2 ещё не реализован. Живые платежи остаются закрыты. Установка и заполнение ключей кассы не открывают их.

Исторические заметки, полные справочники и переводы перечислены в [общем указателе](../../INDEX.md). Старые отчёты относятся к версиям, указанным в их названиях; не используйте их как инструкцию для текущего выпуска.
