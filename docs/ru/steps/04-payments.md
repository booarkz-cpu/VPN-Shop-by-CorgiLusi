# 04. Платежи: что делать по порядку

[Подробная инструкция с нуля до контрольной реальной покупки](../REAL_PAYMENTS_FROM_ZERO.md).

[Отдельная пошаговая проверка каждой кассы и мобильных покупок](../ALL_PAYMENT_PROVIDERS_BEGINNER_CHECKLIST.md).

1. Сначала установите магазин по [инструкции 03](03-vds.md). **Не принимайте реальные платежи**: в 20.0.18 нет полного автоматического staging E2E v2, разрешение на production не выдаётся.
2. Создайте отдельный staging VDS и тестовую панель Remnawave; используйте только тестовые ключи кассы. Следуйте [подготовке staging](../STAGING_VDS_E2E_OPERATOR_20_0_18.md).
3. Для каждого провайдера отдельно проверьте заказ, подписанный webhook, сумму и валюту, одну выдачу VPN, повтор webhook, возврат и отзыв доступа. Запишите обезличенные ID и результат.
4. Если какой-либо шаг не работает или runner не выдаёт полный PASS v2, оставьте платежи закрытыми. Не меняйте флаг в БД вручную.
5. Когда появится выпуск с полным runner v2, проходите [полный порядок проверки и допуска](../PAYMENTS_VDS_BEGINNER_2026_09_28.md) и [описание реализации](../STAGING_E2E_V2_IMPLEMENTATION.md).

Проверка интерфейса или сохранение ключей кассы не подтверждают реальное списание и возврат.
