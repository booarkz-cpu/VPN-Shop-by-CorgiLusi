# v21.0.0 stable — проверенное ядро

Дата: 2026-10-03. Тег: `v21.0.0`. Канал: stable, GitHub prerelease: false.

Этот выпуск фиксирует текущие реализованные функции после alpha.7. Перевод в stable не добавляет незавершённые функции и не подтверждает полную готовность магазина к production. [Матрица покрытия](WORKSPACE_COVERAGE.md) остаётся источником сведений о пропусках.

## Состав

Существующие кабинет, админка, Telegram-бот и Mini App, финансовый журнал, идемпотентность, независимые подписки, конструктор, подарки, аккаунты, поддержка, бесплатные конкурсы и колесо призов. Включены проверенные в alpha.7 [WebAuthn passkeys администратора](ADMIN_PASSKEYS.md) и [операционный мониторинг](OPERATIONS_MONITORING.md). Клиентские/native passkeys не реализованы.

## Проверки и публикация

Релиз публикуется только после успешного полного GitHub CI на точном commit ветки main. CI проверяет backend с PostgreSQL, Support Pro, аудит зависимостей, сборки трёх web-приложений, реальный Chromium с виртуальным WebAuthn-аутентификатором, Compose/контейнеры, Android и iOS. Точный commit и URL успешного CI записываются в опубликованный манифест; не переносите результаты другого commit как новые доказательства.

Архив `remnawave_vpn_shop_v21_0_0_full_release.zip` содержит исходники; рядом публикуются SHA256 и `remnawave_vpn_shop_v21_0_0_full_release_manifest.json`. Исходный архив не является подписанным APK/IPA или готовым образом установленного сервера.

Мобильный workflow запускается также при изменении версии манифеста. Статус Android/iOS опубликован отдельно как `mobile-production-status.json`; без ключей владельца он сообщает блокировку подписанных production-пакетов.

## Обновление

Миграция магазина: `0053_admin_passkeys`; Support Pro: `0005`. После alpha.7 новой миграции нет. Перед обновлением сохраните согласованные backup базы, uploads и настроек. [Пошаговое обновление](WORKSPACE_UPGRADE.md), [проверка отдельного стенда](FINAL_RELEASE_READINESS.md).

Установщик, API, архив и release workflow используют `21.0.0`. Production GitHub Deploy принимает точный тег stable; не обходите платёжный gate после смены канала.

## Сохраняющиеся ограничения

- `production_ready=false`: реальные платежи, SMTP и VPN с сервисами владельца не подтверждены.
- `production_e2e_verified=false`: application E2E v2 не завершён; production-платежи остаются закрытыми. [План реализации](STAGING_E2E_V2_IMPLEMENTATION.md).
- `full_function_transfer=false`: матрица содержит незавершённые рефералы, партнёрский кабинет, редакторы, merge, каналы поддержки, импорт, операторские инструменты, plugin runtime, native push/виджеты.
- `signed=false`: исходный ZIP не подписан; для APK/IPA нужны собственные Android/Apple signing credentials.
