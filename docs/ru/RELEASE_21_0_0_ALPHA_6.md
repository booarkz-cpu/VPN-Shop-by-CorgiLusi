# Отчёт v21.0.0-alpha.6 — 3 октября 2026

## Изменения

Добавлены бесплатные конкурсы и взвешенное колесо призов. Реализация включает API, админку, кабинет/Mini App, фиксированные условия и бюджет, однократное участие, финансовые награды, приватные результаты, уведомления, экспорт/обезличивание и миграцию `0052_giveaways`. Встроенные механики не принимают оплату за участие и не переводят банковские призы. Полная инструкция: [WORKSPACE_GIVEAWAYS.md](WORKSPACE_GIVEAWAYS.md).

Исправлена ошибка автоматического sandbox-выбора: старые Stripe/PayPal/crypto credentials для исторической сверки больше не мешают локальному checkout без поддерживаемой новой кассы. Поимённо выбранная живая касса не подменяется sandbox; production по-прежнему запрещает sandbox.

Исправлен workflow Production Deploy: `image_tag` ранее не использовался Docker Compose и игнорировался, исходники сбрасывались на `main`. Теперь требуется конкретный опубликованный stable `release_tag`, проверяются архив/контрольная сумма и используется штатный update с предобновляющим резервированием и recovery. Alpha/draft не допускаются. Перед этим новый updater должен быть установлен на сервере. Сам deploy в рамках аудита не выполнялся.

Улучшена публикация: сериализация job, дополнительная проверка актуальности main, восстановление неполного draft и проверка размера/SHA256 загруженных assets до публикации. Завершённые релизы не переписываются. Локальный build-release запускает только тесты магазина, исключая конфликтующий отдельный пакет Support Pro; Support Pro проверяется отдельным job.

Переписаны основные корневые README/документация/инструкции/справочники, обновлены актуальные руководства и карта покрытия. Исторические редакции сохранены в `docs/archive/*_BEFORE_ALPHA_6.md`; исторические тесты перенаправлены к ним без ослабления проверок. Лицензия 2.2 уточняет состав авторских модулей, сохраняя прежние разрешения и ограничения; сторонние лицензии не заменены.

## Проверки

Исходная версия: 589 тестов магазина пройдено, 95 пропущено локально. Итоговый локальный прогон: **648 пройдено, 117 пропущено**. Пропущенные PostgreSQL и внешние проверки не засчитываются как успех. CI проверяет PostgreSQL на release commit.

Support Pro локально: **62 пройдено, 1 пропущено** (PostgreSQL).

Веб: typecheck/build admin, cabinet и miniapp прошли; кабинет — 21 тест в 7 файлах. Проверены Python compileall, Alembic head `0052_giveaways`, bash syntax, static audit и Support Pro integration source audit. npm audit по всем трём web lockfiles и pip-audit backend не нашли известных уязвимостей на момент проверки. Отдельные runtime-проверки PostgreSQL, Docker и мобильных сборок выполняются GitHub CI на точном release commit.

Новые регрессии покрывают сроки/бюджет/точность сумм, подтверждение email, ограничения/удаление аккаунта, подписку, обслуживание, предел участия, целые веса и нулевой исход колеса, повтор после закрытия, единственный розыгрыш и приватность. PostgreSQL проверяет последнее место и параллельное участие/розыгрыш, round-trip миграции и отказ downgrade после участия. Updater проверяет точный tag, checksum и отказ для draft/prerelease/несовпадающего/небезопасного тега. Тесты новых руководств проверяют доступность относительных ссылок.

## Ограничения финального выпуска

Это **предварительный выпуск**. [Матрица покрытия](WORKSPACE_COVERAGE.md) всё ещё содержит незавершённые функции: многоуровневые рефералы, полный партнёрский кабинет, расширенные редакторы, merge аккаунтов/passkeys, общий merge/split поддержки, безопасный импорт, операторские инструменты, plugin runtime и native push/виджеты.

Настоящий application payment E2E v2 ещё не завершён; внешние sandbox callbacks/refund/revocation, SMTP-доставка и реальное VPN подключение не подтверждены этим аудитом. Ключи/отдельный стенд не предоставлялись в текущем запросе. Production gate остаётся закрытым. Новых подписанных APK/IPA нет. Полная визуальная проверка браузером и на native-устройствах не выполнена. SQL/CI результаты не заменяют эти внешние проверки.

Manifest сохраняет `full_function_transfer=false`, `production_e2e_verified=false`, `signed=false`. Перевод номера из alpha в stable эти ограничения не устраняет. [Следующие действия и отдельный стенд](FINAL_RELEASE_READINESS.md), [обновление/backup](WORKSPACE_UPGRADE.md).
