# v21.3.0 stable — страницы и персональные предложения

Добавлены редакторы новостей, лендингов и юридических страниц: структурированные блоки, безопасные ссылки, RU/EN, черновики, предпросмотр, неизменяемые публикации, UTC-расписание, история, восстановление и снятие. Публичные страницы и каталог доступны без входа в общем кабинете/Mini App.

Добавлены ручные/динамические промогруппы, атомарное создание персональных офферов, приватный список предложений и проверка аудитории в общем checkout. Квота покупки с кошелька теперь резервируется до выдачи VPN; оплаченный незавершённый резерв не освобождается по таймеру. Добавлены массовое ограничение/восстановление доступа в магазин, свежая проверка состояния перед выдачей сессии и отключение автопродления при ограничении.

Миграции 0059/0060; head `0060_promo_audiences`, Support Pro `0005`. Новые документы и правила входят в backup. Downgrade с данными блокируется. Старый открытый PR #60 с альтернативной 0058 не объединяйте поверх этого тега без переноса оставшихся изменений на актуальную схему.

Обновлены все зарегистрированные текущие руководства, production-регламент, README, CHANGELOG, API и описание состава лицензии. Исторические инструкции и отчёты о прошлых релизах сохраняют свои исходные версии.

Матрица по-прежнему содержит незавершённые функции: объединение аккаунтов, полный импорт исторических VPN/платёжных данных, расширенные внешние каналы поддержки, кнопки/emoji, nDPI/терминал/shaping, собственный MX и DMARC, полный plugin runtime и native push/widgets/passkeys. Внешняя платёжная/SMTP/VPN/restore проверка и собственная подпись APK/IPA требуют среды владельца. `production_ready`, `full_function_transfer`, `production_e2e_verified`, `signed` остаются false.
