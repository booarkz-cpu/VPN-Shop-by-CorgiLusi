## Оставшиеся действия для релиза

1. Отправить локальный коммит в новую ветку и открыть pull request.
2. Дождаться CI на PR, просмотреть diff лицензии и документации, затем выполнить merge в защищённую `main`.
3. Дождаться успешного push CI на точном коммите `main` и вручную запустить `Publish GitHub release`.
4. Проверить тег `v20.0.7`, заметки и отсутствие ошибок workflow.
5. Ветка `cursor/readme-e2e-c0ec` имеет уникальный коммит `338c180`, удаляющий 988 строк README; `main` сохраняет полноценный README. Удалять ветку только после проверки, что этот коммит не нужен. Не удалять ветки автоматически до публикации и сверки истории.

Ни одно действие из этого списка не следует считать выполненным лишь по наличию локального кода.
